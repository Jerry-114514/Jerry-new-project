另取同一历史提交中已公开的`data/tasks.json`第一份原始输入，移除oracle，作为单独的单源工程夹具。扫描成功检出9条记录，三种模式均命中该源；[对照回执](positive-control.json)同时记录路径重命名模式及布尔/整数类型区分检查。这不是正式数据或模型效果，9条命中也不等于9个独立任务。

```bash
python scripts/audit_prior_public_inputs.py --current-tasks PRIVATE_TASKS_JSONL --expected-tasks-hash 67892c44b95f398810c0a6e04848e8072c00913faa08be1c2847bf9c6289cc0c --source-commit 20214fb28ba1c8a4a2be0be075c97e33eedb2ba0 --out NEW_PRIVATE_AUDIT_DIRECTORY
```

协调人须有原冻结公开合同输入及完整本地Git历史；`PRIVATE_TASKS_JSONL`不应含gold或oracle，输出目录须不存在。当前测试材料和私有配对表不在本阶段发布。脚本只需Python标准库，不加载模型、不运行训练、不执行Git对象内容。

结果只支持“在已识别格式中未检出上述精确输入复用”。随机身份字段不同即可使精确指纹不同，不能用零命中证明语义新颖、来源独立或授权完备。此前已记录的[test/train规范化相同及近邻风险](../../../docs/matched-test-similarity.md)保持不变，未删题、换seed、重分配集合或修改正式推断方案。
