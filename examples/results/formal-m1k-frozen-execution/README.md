# M1k：冻结 P1–P4 闭环工程证据

2026-10-22，engineering 范围。AutoDL 全部 **140 项测试通过**；本地 130 项通过、10 项因无 ML 依赖跳过。全部真实端到端工作使用微型 CPU 模型和合成单元任务/审核声明，真实人工审核为 0，正式训练/评测未启动。

本次顺序为：六个训练 worker 及一次恢复 → 最佳权重绑定 → M5 九条件生成/封存/揭晓 → 删除 gold 与参考 → M6 四条件交互/封存 → 恢复独立静态参考评分 → 删除参考并验证完成凭据。原始 review 及执行审核在训练前删除，后续模型阶段均不需要。

M5 保存两例工程视图的 18 条预测、12 条逐例真实目标损失。M6 保存两项合成任务 × 四条件共八条真实模型运行，全部因两 token 生成无法形成合法动作 JSON 而失败，最终合规成功为 0/8；这些错误保留在分母和日志中。该生成长度只覆盖工程失败路径，不衡量模型能力、微调收益或门控效果。

受控单元测试另用明确注入的 pool：故意漏报输入写入时，独立检查关闭的 P1/P2 接受危险修复，开启的 P3/P4 拒绝。这是人工设计的控制逻辑测试，不是真实模型效果或新增独立任务。初次本地替身曾错取路径字段，导致一项失败，修正后五项定向控制测试通过；未据此修改正式语义。

## 原始文件

- `tests-autodl.log`：140 项完整测试；`tests-local.log`：本地跳过记录；`tests-controlled-core.log`：五项定向测试，不与完整数相加。
- `runtime-identity.json`：远程实际源码及环境；`source-comparison.json`：60 个实现/测试文件一致，新增离线重放脚本在远程套件后单独验证，不冒称覆盖。
- `matrix/`：六组真实配置、日志、结果及模型绑定；临时模型二进制未归档，不能据此声称持久备份。
- `matrix/diagnostic-*`：完整 M5 工程输入、gold、预测、损失与完成凭据。工程合成数据可以公开，正式封存 gold 禁止用此路径发布。
- `matrix/execution-interactions/`：全部四条件原始交互、生成、错误及计费；没有离线 metrics。
- `matrix/execution-reveal/`：独立静态参考评分后的新记录、条件/split 汇总及完成凭据，原交互不改写。
- `verification.json`、`diagnostic-verification.json`、`execution-verification.json`：配置、暴露量、M5 与 M6 的重放结果。不是重新执行模型前向。
- `audit-tamper-checks.json`：独立临时副本中改动交互记录或静态参考均被拒绝。

复核命令不需要 ML 依赖：

```bash
python scripts/audit_frozen_execution_evidence.py
```

它重放工具、初始事件前缀、最终指标、新增违规归因、预算和 k 决策，并重算汇总。最终 checksums 用字符串键排序，避免 Windows/Linux 的 Path 排序差异；归档字节保持 LF。

这些结果只完成工程接口验证。真实独立数据与授权/去重审核、双人标注和仲裁、功效与计算预算、正式预注册和协议封存、六次官方 9B 训练、正式 M5/M6、M7 消融、M8 按任务和种子的统计及持久权重备份仍未完成，原 M1–M8 范围不变。
