在126个无上述开发近邻的源任务中，仍观察到B到D的较大诊断错误率差；这表明当前点估计不只出现在被该方法标记的近邻中。该结果不证明语义独立、无泄漏、普遍原创性或开放任务泛化。分层可能与操作族和难度相关，五源精确匹配子集尤其不能支持强推断。

本分析只报告描述性点估计，不新增p值或区间。所有模型、全部种子和五个预定义分层均保留在[aggregate-results.json](aggregate-results.json)，两次新目录输出逐字节相同，见[复算凭据](replay-verification.json)。没有删题、换seed、重分配、调用模型或修改原18项注册统计。

方法继承[M2n原输入规范化及分层定义](../formal-m2n-matched-similarity/README.md)。代码为[scripts/analyze_fixed_overlap_strata.py](../../../scripts/analyze_fixed_overlap_strata.py)，使用--scientific-archive、--scientific-sha256、--scoring-archive、--scoring-sha256和全新--out目录；原始输入保持私有，运行需已授权取得的本机交付材料。代码会核对原方法文件摘要和预评估mask承诺。

公开文件只含聚合计数及点估计，不包含任务ID、输入、gold、模型文本或私有mask。该补充分析不自动勾选M2/M8或证明整体目标完成。
