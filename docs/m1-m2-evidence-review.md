1. M2不能表述为“全部近重复已消除”或“严格IID数据已证明”。最终test是输入规模匹配、要求表述留出的条件性评估；共享生成器、固定操作族配额与保留近邻限制外推。冻结后不依据模型成绩删题、重分配或重生成。
2. 程序生成批次没有使用WikiSQL原始表格，旧WikiSQL开发材料保留但不并入正式合同。生成代码、来源声明及哈希不能证明所有历史公开资产的语义污染均已排除，也不构成法律授权认证。公开范围仍需逐项核查。
3. 证据索引存在性不等于证据在任意自然语言语义上充分；程序标签研究限定于公开、明确编码的规格，不报告人工评估。
4. 正式诊断、四组闭环、六项控制条件、预登记统计与测试材料最终发布仍分别由M5–M8验收。M1/M2的工程材料不能代替这些实验结果，也不能用最终报告中的限制说明冒充未完成实验。
