# 9B 新领域闭环开发报告

本轮从官方原始 Qwen3.5-9B 同时加载执行与分析角色，没有加载历史适配器，也没有训练新权重。在 RTX 5090 上完成四组开发运行，并对原始工具事件、预算和评价结果进行独立重算。

**结果：程序能够执行真实模型提议、接收工具反馈、保存失败和重放；这八个开发源任务上，四组均只有 2/8 合规成功，没有动态策略或独立硬检查的效果优势。**

## 范围和固定条件

数据来自此前公开的八个开发源任务的执行变体：舍入、日期边界、Unicode、稳定排序、缺失/null、半开区间、字面 ID、复制。每项公开输入含四项明确要求及结构化规格，静态参考单独保存。不是新的独立人工基准，不进入正式测试。

最终条件固定为：原始 9B，BF16 本地推理，greedy，context 上限 4096，单次最多生成 512 tokens，每任务共享预算 16384 tokens，最多 3 次修复，每个初始/修复提议最多 3 次工具反馈、累计最多 16 个动作。四组使用相同工具、接受规则和 actor 顶层字段提取策略。

模型自报 `done` 只结束当前提议；成功由离线参考及可信工具事件判断。顶层多余回显字段可以忽略，但不修改 actions/done，也不信任回显的 files/events；原始输出和严格格式标记均保留。

32 次运行仍只有 8 个源任务。四组的工具结果和 token 使用相同，每组合计 20645 tokens、11 次执行调用和 8 次分析调用，没有触发独立检查拒绝，也没有实际候选修复。因此不能从这组数据推断硬检查无效，更不能宣称其提升了成功率。它没有提供观察修复干预效果的机会。

动态策略与 fixed-full 的 token 成本相同。墙钟原样记录，但存在初始加载和顺序效应，没有平衡计时实验，不能用小幅时间差推断效率优势。

## 错误并非都来自接口

按当前未经人工审核的静态参考，舍入和半开区间交付正确；日期任务的报告如实统计了文件，但所选记录错误。另外五个任务仅完成字段验证，没有生成交付数据和报告。

分析器在缺失交付物时仍可能判断结果 satisfied，或把可证明的未交付判为 unknown，因此没有启动纠偏。复制任务还引用了不存在的证据键，在线门禁把整个分析转为 unknown。这些是必须保留的失败，不应通过读取 oracle 决定修复目标来掩盖。

以一组八任务的初始分析作描述性分解：

- 8/8 是合法 JSON，结构符合 findings Schema。
- 7/8 通过在线引用存在性等检查；引用存在不等于证据语义支持正确。
- 对原始状态词按程序参考比较，错误为 11/32；在线引用门禁后的弃权状态错误为 13/32。此处不修改模型状态或引用，也不把一个无效引用输出描述成四条无效 JSON。
- 执行端所有 11 次可解析响应都带多余顶层回显字段，原生严格包格式合规为 0/11。字段提取后能够执行，不等于模型原生格式已正确。

这些指标来自开发数据和程序参考，不是人工确认的泛化结果，也不能与旧合成微调试验直接混比。其他三组重复了相同源任务，不能当作新增独立诊断样本。

## 工程验证和可重算证据

1. 本地 98 项检查中 91 项通过、7 项因未安装 ML 依赖跳过；AutoDL 现有 ML 环境全部 98 项通过。
2. 新领域规则基线在静态参考上全部通过；故意破坏公共求解器后，独立评估仍判错。相互独立的参考机制已验证，参考的科学正确性仍需人工审核。
3. 受控测试覆盖：跨调用写后恢复、初始不可逆问题分层、修复新引入违规、报告依赖回归、部分初始动作后的错误、步骤上限、真实字段检查结果、布尔/整数改写、日志重放及预算伪造。
4. 最终 32 次和早期开发协议的 64 次记录，共 96 次，均已重放工具并重算初始/最终评价、违规归因和 token 账本。见[重放审计](../examples/results/formal-m1d-development/replay-audit.json)。
5. 当前官方 9B 的 13 个资产重新匹配固定版本，运行模块内容哈希、环境、数据哈希及原始输出一并保存。早期开发迭代没有完整独立源码封存，只保留失败轨迹作审计，不作为正式可复现实验或质量比较。

根目录见[本轮资产](../examples/results/formal-m1d-development/)。复现命令和接口语义见[执行合同指南](execution-contract-guide.md)。

## 标注与后续

最终 32 次记录按完整公共观察去重得到 8 个自然执行视图，仍为原有 8 个源任务。已生成不附模型判断、oracle 指标或方法标签的盲标注包和空白双人审核表；人工审核完成数仍为 0。

下一步必须扩大新来源任务，人工核验参考与状态/证据；补齐正式执行与冻结协议绑定、未知或无法修复情形的控制、动态纠偏强度及消融，再冻结强提示与训练配置。六组正式 9B 训练、独立测试和确认性四组闭环均未启动。

本轮没有证明任何学习率创新、真实任务泛化、评分校准或动态控制收益。稳定产出是可运行的工具反馈闭环、独立评估与重放、可审查的自然失败轨迹，以及明确保留的负结果。
