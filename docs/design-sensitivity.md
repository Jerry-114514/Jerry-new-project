# 正式实验样本量敏感性：假设计算，尚非经验功效

2026-10-23。本轮不读取任何题目、标签或模型成绩，先检查200源任务规模的解释边界。代码为[scripts/power_sensitivity.py](../scripts/power_sensitivity.py)，完整80行假设网格见[M3i结果](../examples/results/formal-m3i-design-sensitivity/sensitivity.json)。这不是实验成功率预测，也不批准正式样本量或预算。

RQ1的单位是同一源任务先合并全部证据视图后的状态错误率，再做模型间配对差；每个差值位于[-1,1]。四视图、每视图四要求不提供16个独立任务。三个训练种子需单独报告波动，不把200任务变成600个独立任务。规划计算条件于固定模型；当前还没有正式D与B的开发配对效应或种子方差。

## 正态近似敏感性

以双侧alpha=0.05、目标功效0.8，假设任务差值标准差sigma，候选真实错误率改善delta；正态近似检验功效为Phi(delta sqrt(n)/sigma-z)+Phi(-delta sqrt(n)/sigma-z)，其中z为标准正态97.5%分位数。表中标准差是假设，不是实测。

| 假设任务差值标准差 | 200源任务对5个百分点效应的近似功效 | 相同假设下80%目标功效的近似样本量 |
| --- | ---: | ---: |
| 0.10 | 约100% | 32 |
| 0.20 | 94.2% | 126 |
| 0.30 | 65.4% | 283 |
| 0.50 | 29.3% | 785 |

样本量公式ceil(((z_0.975+z_0.8)*sigma/delta)^2)为规划近似。该表不是冻结后的聚类bootstrap/符号翻转检验的校准功效，不能据此声称当前实验有94.2%的成功率。

## 保守有界差值检查

对独立、范围[-1,1]的源任务配对差，用[Hoeffding原论文](https://www.tandfonline.com/doi/abs/10.1080/01621459.1963.10500830)的有界独立变量尾界，可得到Pr(|均值−期望均值|≥t)≤2 exp(-n t²/2)。在双侧0.05与80%功效下，一种保守充分条件为delta≥sqrt(2 ln(2/0.05)/n)+sqrt(2 ln(1/0.2)/n)。

据此，n=200时充分效应约31.9个百分点；5个百分点的充分样本量为8138。这是最坏情况的充分界，**不是必要样本量，不证明200任务一定不足**，也不替代最终统计方法。独立性是前提而非本脚本的结论；固定生成器、共享模板及已发现近邻仍需限制推论。
