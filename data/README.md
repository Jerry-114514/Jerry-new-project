# 合成开发数据说明

本目录全部是代码生成的虚构记录，不含用户原始 PDF、个人信息、真实客户数据或模型密钥。用途是验证实验工具，不是独立人工标注的正式基准。

## 内容

- `tasks.json`：40 个任务，覆盖去重、过滤、聚合、字段投影、缺字段停止、多文件分流六类操作。
- `diagnostics/trajectories.jsonl`：160 条可重放轨迹，每任务包含合法、违规、正常修复、引入退化的修复。
- `diagnostics/diagnostic_views.jsonl`：320 个完整或隐藏历史的诊断视图，含逐项标签；每条包含 4 项要求。
- `diagnostics/manifest.json`：数量、数据指纹与切分规则。

## 真值与访问边界

`tasks.json` 的 `oracle` 是显式预期交付物和阻断条件，仅最终评估读取。执行器和在线规则分析器接收 `public_task()` 的副本，其中不含 `oracle`。评估器不调用执行器的求解函数，避免用同一个执行算法给自己打分。

这些静态预期值由生成器的显式算术和记录构成。数据尚未经过独立人工标注审查，不应称作真实用户意图真值。源码及数据公开意味着任何有意读取仓库的模型都可能看到答案，因此它们只能作为开发集；正式模型评价须使用隔离的新测试数据及运行权限。

## 切分

轻量分类训练固定按操作族切分：训练为去重、过滤、投影和字段校验；验证为聚合；测试为分流。同一任务的四种轨迹和两种证据视图不会跨集合。输入数字与规则特征的分布仍较简单，验证和测试特征可能非常相似，不能据此宣称真实任务泛化。

受控错误是人为构造的，不能用于估计真实模型的错误发生率。多个视图、脚本重复运行不是独立样本。

## 重建

```bash
python -m intentlab build-data --tasks runs/rebuilt/tasks.json --out runs/rebuilt/diagnostics --count 40
```

请将现有正式数据与开发生成物分开；默认命令读取已有 `tasks.json`，只有显式指定 `--overwrite` 才重新生成该文件。
