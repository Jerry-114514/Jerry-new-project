2026-10-23。按idea.md 2.0的程序标签路线构建新的候选批次。此处是数据构建与复核证据，不是正式协议冻结或模型测试结果。

共1050份合同、4200视图、26个模板。训练/开发/test覆盖八个操作族：十进制舍入、带时区日期过滤、Unicode NFC、稳定排序、缺键与null、半开区间、ASCII筛选投影及日期格式转换。OOD保留保序去重、条件分组求和两族，不进入train/validation，也未对其进行模型评估。新操作有单独的公开求解和独立参考实现、手写边界夹具。

## 来源、模板和统计边界

每份合同由私有256-bit split seed和HMAC派生的单源随机流生成，四个划分种子互异。全部数据为程序生成，不是1050份独立人工设计问题；统计解释应以固定生成器/操作族下的源抽样为限，不能仅凭随机种子宣称语义独立。该批不含第三方原始表格，不复用旧WikiSQL或已公开开发任务的记录。

同一合同的视图保持相同source_task_id、模板与划分。train采用单输入文件，validation采用双文件并增加必需字段，test采用三文件和更多字段；OOD采用保留操作族。请求明确指定输入合并顺序、required fields、操作参数、路径、历史约束、类型和报告计数。模板差异包括文件布局和必需字段，不能只按重命名后的ID宣称隔离。

**当前test是已见操作族下的结构模板移位，不是严格IID。** 三文件布局未在当前单文件训练中出现，输入规模和长度也有偏移。正式冻结前须明确该估计对象，完成长度/规模匹配与功效审计；不能在论文中直接把它称作严格同分布泛化。操作族OOD与结构移位分别报告。来源隔离检查拒绝跨源/划分的精确原始输入复用，但不证明全部近重复或语义独立；剥离随机标识后的重复风险仍需审计。

## 标签、故障和修订记录

每源四个视图：完整交付、按源内索引预先轮换的单故障、组合故障、隐藏历史。单故障包含先写后验、报告计数布尔化、输入删除后恢复、结果错误但报告计数真实。结果错误尽量保持合法记录与数值类型，例如错误舍入、未规范化、稳定次序错误、遗漏筛选记录、重复去重结果或聚合总额差1，避免一概用明显占位对象制造容易检出的错误。

初版占位结果批次、第二版及最终v3候选目录都保留在本地私有runs，使用同一组私有种子；源合同和参考不变，修订仅改善视图构造。生成器首稿快照及原计划另存，后续代码以提交身份和文件哈希追溯。所有修订都发生在任何新批次模型调用之前，不根据测试成绩选题。

64份train/validation缺字段合同已纳入独立blocked故障矩阵，覆盖正确阻断报告、迟校验、无校验、禁止数据产物、输入恢复、错误报告计数、隐藏历史和缺报告。750份开发合同共构建8744个故障视图，六种声明的标签器变异均有反例；1050份固定参考与公开求解逐一一致，并通过独立参考复算。标准库数值/日期/Unicode原语仍是共享依赖，不称形式化证明。

本地与AutoDL重新生成的任务、参考、视图、标签摘要及程序验证/源隔离记录一致。AutoDL226项测试全部通过；本地226项中14项ML测试跳过，跳过不计为通过。

## 私有性与复现

实际split种子由`secrets.token_hex(32)`生成，不放入GitHub。公开[生成计划](../configs/procedural-data-plan.json)、代码、种子承诺哈希和数据摘要；原题、参考、完整标签、全部种子保持私有。代码和公开计划本身不能重建实际测试题。单元测试中的固定小种子仅生成单元夹具，不用于研究批次。

```bash
python scripts/build_procedural_data.py --plan configs/procedural-data-plan.json --private-seeds /private/split-seeds.json --out runs/new-procedural-batch
python -m intentlab.programmatic_protocol --cases /private/batch/cases.jsonl --tasks /private/batch/tasks.jsonl --references /private/batch/references.jsonl --execution-tasks /private/batch/execution-tasks.jsonl --execution-references /private/batch/execution-references.jsonl --out runs/new-evidence
```

输出目录必须不存在，保留失败/旧批次；协调人重建只用于生成与核验，不读取模型测试输出。完整私有内容在本地和AutoDL各有一份，不把这等同于完成M8长期模型备份。公开[M2j证据](../examples/results/formal-m2j-procedural-candidates/README.md)只含摘要、哈希及复核程序。
