# 完整600视图开发集的强少样本基线选择

2026-10-23。按先前M3h计划完成官方原始Qwen3.5-9B三条件共1800次调用，之后统一评分，未根据中途成绩改方案。原始预测、账本和程序标签已私有备份到本地；本地按原解析/评分规则逐项复算，三份完整评分报告及选择结果与AutoDL一致。测试/OOD未参与。

各条件共享150个源任务、600证据视图、2400要求判断；统计单位仍是150源任务。此批全为明确规格的程序注入视图，gold是程序标签，不声称人工验证或自然任务总体泛化。

| 配置 | 任务平均状态错误率 | 错误判断/2400 | 严格格式有效/600 | 条件墙钟 |
| --- | ---: | ---: | ---: | ---: |
| A：完整Schema零样本 | 24.79% | 595 | 600 | 67.96分钟 |
| B3：三个训练示例 | 15.96% | 383 | 596 | 94.47分钟 |
| B4：四个训练示例 | 19.75% | 474 | 581 | 100.12分钟 |

依据事前规则：仅在B3/B4中，选任务平均normalized状态错误率最小者，同分依次比较strict错误与较少示例，故选择**B3**。三个示例覆盖完整交付、组合违规、隐藏历史；均来自训练来源，与验证源/模板隔离。B3比A减少8.83个百分点；这不是微调收益，也不是独立测试效应。

三条件各有0次生成异常、0个缺失输出，均未触及512生成上限。然而B3的4个、B4的19个完整响应违反“证据引用唯一”规则，整条响应的判断按原规则计错。未删除重复引用、放宽解析器或丢弃失败。不能把“调用异常0”写成“模型错误0”。此次B4配置的负结果完整保留；它不能推广为所有四示例提示必然更差。

在300个gold unknown判断中，A正确0、B3正确138（46%）、B4正确117（39%）。在678个“硬要求gold非satisfied”的机会中，错误肯定satisfied分别为396、220、221，分母包含unknown；该指标仍有明显风险，不代表安全已解决。证据索引存在性另行记录，不等于证据语义支持已被验证。

B3选择和效果比较用的是同一开发集。原方案任务bootstrap给出的B3−A区间[-10.46,-7.13]个百分点仅作选择后的描述性区间，不作确认性显著结论；本次评分未事后改用新v2分层方案。强基线选择尚未随正式协议冻结，新自然视图的额外验证、资源/功效预算、控制器选择与测试封存仍待完成。
