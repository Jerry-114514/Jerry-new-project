# 三轮注入修复与长历史开发覆盖

2026-10-23。idea.md要求多次修复和长历史，原4注入视图及none自然轨迹不足以覆盖。新增独立开发构建入口，按split/操作族/初始blocked状态分层，取task_id SHA256最小者；不按模型成绩、长度或标签难度挑选。每个开发集合16源、32视图，共64视图，新增源为0。原数据不修改，测试/OOD的新历史视图尚未构建，不切换正式协议。

每个源包含三个明确注入的修复轮次，每轮重复8次可信字段验证，再修复错误输出（有效输入时）及错误报告；blocked源仅写允许的报告。两种最终视图分别为正确修复后状态，以及早期删除/恢复受保护输入后经历相同长后缀的状态。两者最终文件完全相同，31–40个实际重放事件中的历史违规仍须保留；blocked时输入写入还违反顺序限制。不是实际模型多轮修复成功，也不证明开放任务的长历史多样性。

三个针对性检查覆盖所有可用split/族/blocked分层的顺序不变选择、同终态不同历史的独立程序标签，以及早期事件篡改拒绝。首次测试误把label_case返回字典当列表，测试报TypeError；改为读取findings后3项通过，未改标签器或可信工具逻辑。开发数据已实际生成并完成程序导出。
