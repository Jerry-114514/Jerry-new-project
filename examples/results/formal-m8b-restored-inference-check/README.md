# 恢复权重实际加载与推理验收

修复后的探针在原RTX 5090上实际退出0：恢复的官方基础模型及六份验证所选LoRA导出均完成有限前向及1–8个新token的有界生成。使用BF16、不量化、不加载优化器状态，适配器张量逐项等于恢复的safetensors。实际输出见[probe-status.json](probe-status.json)，复制到本机后的字节校验见[off-host-verification.json](off-host-verification.json)。

首次尝试完成基础模型及第一个适配器的生成后，因删除活动适配器导致下一次PEFT加载出现KeyError。其[实际失败状态](first-attempt-failure.json)保留。修复先加载和激活下一个适配器，再删除旧适配器；第二次使用全新输出目录，不重跑正式科学评估，不修改冻结源码和预算守护。

固定公开提示的文本并非任务质量评估。探针仅证明这些恢复文件在该依赖环境中可加载及运行，不证明训练断点恢复、长上下文覆盖、原输出逐位等价或新环境重建。独立探针峰值显存不能回填M6/M7缺失的正式资源测量。本检查不等于M8整体验收。
