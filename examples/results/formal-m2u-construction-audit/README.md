# 最终数据构建与质量检查的实际证据

本目录只公开聚合核验信息，原合同、gold、生成种子及模型输出仍在用户私有交付包中。它提供验收事实，不把文件标志当作普遍语义独立性证明。

- [构造隔离](constructor-isolation.json)：在禁用常见Python文件、网络和子进程入口期间，使用原计划、五条已承诺随机流及生成源码重建1050份合同，全部冻结JSONL字节相同；构造时不读取旧任务文件、模型输出或参考答案。该检查不是对恶意代码的通用安全沙箱。
- [完整合同及源划分](operational-dedup.json)：签名排除任务ID、source ID、split、模板名及来源元数据，保留所有实际输入、规格、要求原文和输出合同；完整合同重复配对0、跨划分重复0；4368视图的1050源没有跨split派生。4304注入视图与64自然视图分别记载。
- [程序标签、参考与故障检查](validation-aggregate.json)：4368标签重算与原标签canonical一致，1050合同/十操作族与独立参考一致，8744开发故障视图/34976要求无场景预期分歧，六类声明变异均检出。不是形式化证明、human evaluation或穷尽故障覆盖。

完整合同唯一不等于规范化后无近邻。M2n的6个规范化完全匹配配对、165个近邻配对及其风险保持不变，不在揭晓后删题。新增[输入分层补充分析](../formal-m2v-overlap-sensitivity/README.md)仅作探索性描述，不将未标记126源替换为主测试，也不据效果较好判定数据独立。

新合同由不同源流构造，不是把旧公开合同或训练合同逐题读入再改写后移到测试。匹配test的reword只作用于本轮新流构造的test合同。确定性构造与I/O入口检查说明这一实际路径；它不证明无既往概念影响、全部互联网资产语义排除或严格IID。

方法见[audit_frozen_contract_regeneration.py](../../../scripts/audit_frozen_contract_regeneration.py)及[最终逐项核对](../../../docs/final-data-requirements-audit.md)。对数据构建及明确声明检查的验收，与研究中仍需假设的源簇独立性和配对可交换性分别报告。
