# 完整与压缩提示的真实模型开发对照

2026-10-23。固定计划见[对照计划](compact-prompt-comparison-plan.md)。已完成104个开发视图的两条件208次原始9B推理，全部调用保留，生成异常均为0；没有人工真值或正式测试结果。

模型、输入与顺序固定：偶数视图先full后compact，奇数相反；单模型常驻GPU，贪心生成，每次重置账本，上下文6144、最大输出512、每次预算8192。6144是推理配置，不是训练长度已通过。原始模型资产在结束后核验13项通过。

压缩提示的提示token减少34.04%，总计费token减少31.68%，本次生成阶段累计时间减少9.45%。这些是同一工作负载的描述性观察，不是总体速度保证、统计显著性或训练时间估计。整次进程约1270秒，包含加载、预处理和写盘等；生成计时不等于整次耗时。依赖版本在运行后采集，非外部执行证明。

引用约束只核验引用实际存在及known状态有非空引用，不能证明引用语义支持结论。解析失败保留；没有去掉围栏、重试或事后扩大归一化规则。

## 数据可还原，模型行为仍有变化

双侧均可解析的99个视图共396项判断中，状态不同40项；另5个视图、20项因至少一侧不可解析而不可比较，总分母仍为416。99个可比较视图中有70个全部状态相同；引用集合不同230项。

**40/396是预测分歧，不是误差率。** 没有人工真值，无法判断哪种提示更准确。完整public、Schema和证据目录值可以确定性重建，并不保证模型输出不变。两条件有效预测数不同，预测状态总数也不宜直接解释为违规召回率的变化。

104个视图关联32份合同、24个声明来源；部分为同任务的多个注入/自然视图，来源独立性尚未核验。没有把视图当独立任务计算显著性，也没有将本轮写作正式M5或微调收益。

## 下一步与复现
