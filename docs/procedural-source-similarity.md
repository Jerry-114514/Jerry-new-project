# 程序候选输入相似度检查

2026-10-23。在正式冻结前，对v3候选1050份公开源合同做输入相似度审计，未读取参考文件、gold或模型输出，不修改数据。私有题目只用于构建/隔离审计，未进入提示选择。完整结果在本地与AutoDL复算一致。

旧精确哈希检查保留随机rid、路径及tag，可能掩盖底层内容相似。本轮补充去除这些表面差异的描述性检查：去掉rid值、tag值、文件边界和路径，把操作字段按语义角色重命名；保留操作参数、JSON值和类型、按路径拼接的行序以及每行缺少必需字段的数量。只比较相同操作族及相同操作参数的跨集合任务。按行token计算Levenshtein编辑距离，除以较长行序列长度，预设0.25阈值用于列出风险，不作为自动验收或删除依据。

两对开发集风险分别来自稳定排序、缺键筛选；均仅相差一行，规范化距离1/6，共涉及四份源合同。完整配对ID及规范化指纹保持私有。未删题、换集合或改变正在运行的基线验证集。后续冻结应保留此风险及开发选择对近邻的敏感性分析，不能称“无近重复”。

这不是语义独立证明。不同集合的文件数和总行数本来不同，零完全匹配可能由该结构直接造成；相同生成器、要求骨架、故障逻辑仍共享。0.25阈值不是经验验证过的泄漏概率模型；没有覆盖跨操作族语义等价，也没有测量全部约束组合、历史长度的相似性。两个保留OOD族与开发操作不同，故未纳入相同参数配对，这不等于完成全部OOD相似度审核。

当前test依然是结构模板移位，严格IID测试缺口未因此解决。正式数据与统计解释仍需符合idea.md要求；不能仅凭本轮零测试近邻就批准冻结。公开[驱动及摘要](../examples/results/formal-m2k-source-similarity/README.md)，原始合同、配对清单、种子及答案不公开。
