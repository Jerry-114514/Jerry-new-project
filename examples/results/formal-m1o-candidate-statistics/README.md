## 复核

```bash
python scripts/audit_statistics_stage_evidence.py
```

该命令先核验开发选择、M5/M6/M7，再重放候选并重算统计。`matrix/statistics-analysis/manifest.json` 绑定上游三个凭据、协议、模型及统计设置；`report.json` 明确 `m8_complete=false`。模型二进制未包含，离线复核不运行前向，不等于持久权重备份或实时模型资产验证。

`tests-autodl.log` 和 `tests-local.log` 保存完整测试；`candidate-import-failure.log` 保存最初隔离发现的导入失败，修正后全套重新通过，不将该开发失败写成模型实验结果。`runtime-identity.json` 和 `source-comparison.json` 保存环境及源码匹配证据。`audit-tamper-checks.json` 记录归档修改的拒绝检查及历史报告兼容性。
