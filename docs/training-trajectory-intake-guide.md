# 自然轨迹训练候选与标注接入

2026-10-23。本轮推进 M2 的训练候选，不建立正式测试集，不替代独立人工审核。所有新任务均为模型编写的合成场景，未读取外部真实用户数据。

## 新候选批次

`scripts/build_training_candidates.py` 静态编写 12 个 train 变体，覆盖退款、费用、图书标题、站点别名、诊所队列、仓库、传感器、同意记录、库存和调查等场景。为避免把换领域、换字段或换数字当成独立任务，按四个操作模板保守归为四个 source_task_id，而不是声称 12 个独立研究样本。它们与旧开发题共享操作；仍须跨新旧数据做语义近重复审核，不能直接把这四簇与旧八题相加为 12 个独立来源。

在 AutoDL 5090 上，官方原始 Qwen3.5-9B 执行这 12 个候选，策略 none、最大修复数 0、每次生成上限 768、单任务总 token 上限 8192、上下文上限 4096、最多三步工具反馈。保留既有 extract 格式处理；不训练、不选择学习率、不运行测试/OOD。公开规则分析器用于开发检查，静态参考仅在交互后评分，不提供给执行器。

实际执行得到 21 次调用，静态参考下 5/12 完全合规、7/12 未完成要求；不是诊断微调前后比较。全部 21 次调用都经过格式投影，严格执行器响应合规计数为 0，必须保留原始响应及该处理规则，不能将提取成功写成原始接口成功。参考为独立于规则求解器静态编写的候选值，尚无人核验，因此这些成功/失败也不是正式人工真值。

## 从原始记录制作盲包

```bash
python scripts/build_training_candidates.py --out runs/training-candidates-v1
python -m intentlab.trajectory_intake --tasks runs/training-candidates-v1/tasks.jsonl --execution RUN_DIRECTORY --out runs/training-annotation-v1
```

执行命令及实际参数见[原始证据](../examples/results/formal-m2a-natural-training/README.md)。导入要求完整的 development 运行清单、真实模型执行声明、任务哈希、模型路径、全部任务/策略记录及原始生成或生成失败凭据。逐事件重放后必须精确复现最终文件；失败不能丢弃。记录声明与回放一致不等于证明模型真实性，环境和原始日志仍需审计。

每条运行生成两个可见性视图：完整可信事件、仅文件快照。视图继承同一 source_task_id、模板和 split，不成为新独立任务。`source.origin` 保留 model_generated，`source.trajectory=natural` 仅表示轨迹来自实际模型尝试，不意味着题目由人编写或经过人工核验。

协调人保存 `coordinator-cases.jsonl`、`coordinator-provenance.jsonl` 和 manifest；给 A/B 的 `reviewer-packet` 只含 case_id 与公开观察、空白模板和说明。不能发放原始模型回答、规则诊断、metrics、参考输出、方法身份或协调人来源映射。工具不读取参考，不自动生成状态标签，不填写审核者身份。输出目录不得覆盖；输入不全或回放失败时不创建标注产物。

本批次为 **24 个视图、12 次原始执行、4 个保守来源簇、每人 96 项要求判断**。A/B 两人合计 48 条初审记录、192 次逐要求判断。先按[通用人工流程](human-annotation-workflow.md)独立提交，再用协调人的完整 cases 合并、生成分歧并由第三人仲裁。真实人工审核当前仍为 0。

## 边界与下一步

该入口拒绝 test/OOD，不能把未来封存测试导入公开开发包。自然错误并不保证类别均衡、证据语义有效、历史足够长或来源独立；应在训练/开发候选上做覆盖检查，再补充明确标记的注入轨迹，不得伪称自然失败。

这批数据远未达到 idea.md 的 600–1,000 个独立训练任务目标；真实新来源、审核人员、近重复/授权审核、正式数据划分、功效与预算、冻结和六次训练仍缺。正式准备检查不能因为新增这些未审核变体而自动转为 ready=true。
