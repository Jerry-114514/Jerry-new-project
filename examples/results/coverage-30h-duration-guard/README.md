# 新增30小时时长保护：实际部署记录

[实际核验](verification.json)记录原实例上的守护存活、9项Linux单元测试，以及配置/状态异机字节校验；本地完整382项测试通过，16项跳过。原500元费用守护未改动，新增模型任务为0，模型执行范围仍待确认。

时钟固定从北京时间2026-10-27 22:10:12起算。这个已知时点早于用户提出30小时上限，保守计入准备与空闲时间；不以未来训练开始时间重置额度。最多30小时，并取原费用停止线的更早期限；第28小时关闭新任务入场，第29小时启动停止/关机流程。重启、时钟回退、旧守护失活或配置变化均不能续期。

代码：[additional_gpu_time_guard.py](../../../scripts/additional_gpu_time_guard.py)。`install`使用全新独立目录及原费用守护配置SHA，须指定固定`--start-unix`；`watch`恢复原配置，不能重设起点；`admit`验证两个守护实际PID/start ticks、心跳和任务可容纳时间。

`admit`不运行或计时任务。阶段执行器必须另外设置超时并持续核验守护。过期处理重新检查工作进程归属，预留中断保存时间后停止任务，再请求AutoDL官方关机。

本记录没有执行实际过期关机试验。关机命令返回成功也不等于已核实停止计费；仍须协调端确认实例/服务商状态。此安装是预算上限保护，不授权新模型训练，不表示正式协议已冻结或实验已完成。
