# M2g：600份单模板训练开发候选

固定上游train归档、结构限制和选择seed不变，来源池从600扩到3000；851条满足现有ASCII文本等值适配，按已选page_id和精确表内容去重后可用724条，确定性取前600。它们是600个暂定页面组、一个项目模板，均无人审核。

原12份合同、48个注入视图是新批次前缀，字节内容对应的规范化哈希完全一致；本轮新增588份合同、2352视图，总量600/2400，不能再加旧12/48。没有新增真实模型调用、自然轨迹、正式测试/OOD或人工标签。

`pool-manifest.json`记录3000来源的摘要与私有内容指纹，未发布3000条原题/表格/SQL；`lineage-public.jsonl`只含选中600份合同的来源指纹与未审核声明，故障映射仍私有。`prefix-consistency.json`与旧M2c/M2d证据交叉绑定，`private-file-sha256.json`绑定pool/adapted的全部文件。

`program-reference-consistency.json`对应600份公开程序与另一实现SQLite候选参考的一致性检查，不是模型准确率或人工语义验证。`source-quality-summary.json`显示3000来源有2988个精确表内容、1947个已提供page_id值及634条缺失，来源池自身不等于3000个独立任务。

盲包2400条、每人9600项判断，未分发，来源/适配/授权及人力预算未完成。源合同和答案继续私有，只公开盲包哈希及工作量。600份合同共有179700个两两组合，本轮仅记录公式，没有生成或完成这一数量的语义审核。

`audit.py`默认仅核对元数据；`--private-root DIR`核验真实私有文件、前缀、空标签及程序一致性；`--archive PATH`从固定上游train完整重建3000来源和600份适配，重算所有字节哈希。未运行新推理或训练。源码与范围见[规模准备报告](../../../docs/training-candidate-scale.md)。
