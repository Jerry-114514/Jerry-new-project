# 保持损失定义的训练显存优化

2026-10-23。此前全量候选长度检查显示压缩提示最长3690 tokens，加512输出预留需4202；旧实现4096-token合成压力曾OOM。本轮从工程实现减少不必要的输出头开销，没有删减输入证据、监督标签或训练目标。

## 实现与一致性

旧 `token_loss` 对全部输入位置生成词表logits，再将完整矩阵转FP32，尽管大部分提示位置的标签为-100、不参与损失。新实现先取因果位移后的监督位置。基础模型明确提供 `logits_to_keep` 参数时，在输出头之前选择这些位置；PEFT包装通过基础模型签名识别，不能仅凭接受任意kwargs认定支持。其余模型保留完整前向后选择位置。

批次内取各行监督位置的并集，再用逐行有效标签掩码排除其他行的提示和padding；输出头之后仅将有效目标的logits转FP32。交叉熵仍为相同因果目标的求和，训练和评估共用此函数，目标token加权规则不变。没有监督目标直接报错，模型不遵守选择后的输出形状也报错。

新增检查覆盖不同提示长度、padding、监督位置中间空洞、PEFT风格包装、无目标失败以及不支持参数的回退路径，比较损失和全部参数梯度。另用真实Qwen3.5架构的小随机模型加LoRA、非零B矩阵比较损失与全部适配器梯度；CPU容差内通过。此为数值一致性检查，不承诺GPU不同矩阵形状下逐位相同；正式比较须统一使用本实现和固定代码版本。
