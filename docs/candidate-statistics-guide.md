# 候选审计与统计阶段验证

2026-10-25状态说明：六次正式9B训练及六份端点跨主机备份已核验，M5正在生成，M6/M7及正式统计尚未完成。下面保留2026-10-23入口设计；当前采用程序标签，无人工标注依赖。[M8复算与发布验收](formal-reproduction-acceptance.md)说明正式结果的后续验收，入口可用不代表M8完成。

## 候选机会与误拦截

交互只保存公开输入、动作、接受决定及 `proposal_complete`，不读取测试 gold 或独立执行参考。全部交互封存后，评分入口才打开参考，对每个修复候选从当时已提交状态重新执行。被拒动作不进入后续提交状态；全部已接受候选必须精确重现最终文件与事件。

`proposal_complete=true` 表示有界提案阶段已经正常返回，不表示任务已完成或所有要求合规。生成、解析或工具阶段中断的候选保留在尝试分母，但其合规真值、误拦截和新增硬违规均为 null。完整提案返回后才发生的分析器错误仍是完整候选，不能借错误排除有利或不利的候选。

主描述计数为“完整且经离线参考判断完全合规，但未被接受的候选”。同时分解独立检查明确拒绝及决策错误的计数；不能把所有未接受均归因为独立检查。分母只包括完整且完全合规的候选，分母为零时比率为 null。另报源任务内比率的等权均值、各源分母、未完成提案和新增硬违规。候选机会随条件变化，这些是描述性机会率，不是全部任务上的因果处理效应。参考正确性依据独立程序实现、差分及声明的故障检查，保留覆盖限制；不声称人工审核或形式化证明。

## 共同初始可行子集

RQ2、RQ3 与 M7 的辅助对照只在同一任务、两个条件均初始可修复的交集上配对。分别保留共同可行、仅左可行、仅右可行和两侧均不可行的数量；先求同源变体均值，再对源任务等权。空交集的估计为 null。

该选定子集只作描述，不替代全部任务的主分析，不增加确认性 p 值或改变登记的 Holm 家族。条件各自可行的两个不同集合不能直接作为成对比较。

## 统计阶段入口

`python -m intentlab.frozen_statistics run` 要求下列参数：

```text
--protocol LOCK --binding MODEL_LOCK
--predictions M5_RAW --diagnostic-reveal M5_SCORED
--execution-interactions M6_RAW --execution-reveal M6_SCORED
--ablation-interactions M7_RAW --ablation-reveal M7_SCORED
--out NEW_STATISTICS_DIRECTORY
```

工程协议必须另加 `--engineering`；正式协议不能靠该开关绕过审核。输出目录必须全新。入口在计算前后递归核验 M5/M6/M7、模型和训练凭据，并绑定协议、模型、统计设置及三个上游完成凭据。它读取已评分记录，不重新读取 gold 或执行参考。

`verify` 使用同一组输入，改为 `--statistics DIRECTORY`，不仅验证哈希，也重算登记算术并比较完整报告，防止重算哈希后修改检验家族或结论。相同冻结分析可以在新目录复现；这不是再次揭晓测试标签。报告和凭据始终标记 `m8_complete=false`，统计阶段完整性不能证明科学假设成立或模型已长期备份。

旧工程记录缺少显式候选阶段标记，不能推断回填成零候选；旧评分和统计接口保留原默认模式。新的 M6/M7 评分显式开启候选审计，统计阶段入口要求完整审计。历史结果保持原样。

公开工程证据的复核入口为 `python scripts/audit_statistics_stage_evidence.py`，先重算开发选择、M5/M6/M7，再验证候选、统计及凭据。它不运行模型前向，不替代持有实际绑定权重时的完整验证。正式封存资产禁止通过工程归档路径发布。
