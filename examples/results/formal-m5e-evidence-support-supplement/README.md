# 证据支持补充评分：实际结果及复算

在正式M7封存、评分、统计和异机备份完成后，对原先封存的九条件诊断输出执行补充离线评分。每条件1240视图，保留缺失和解析失败分母；实际评分与全新目录复算退出码均为0，十个原始输出文件逐字节一致，见[凭据](replay-verification.json)。未调用模型，未修改原正式评分。

[aggregate-summaries.json](aggregate-summaries.json)保留严格及归一化两种模式的总体、split、规则和split×规则全部聚合计数、分母、源任务等权均值与micro结果，仅省略逐源任务映射和原始逐例记录。它是原输出的聚合投影，不能将投影SHA256说成原输出SHA256。原输出校验值单独保留。

该新增指标属于**探索性**：它评估明确编码规格内引用是否构成充分见证，不评估任意自然语言蕴含，不声称人工验证，不新增确认性p值。unknown作为弃答单列，不当成已知状态的支持成功；空分母保持null，不能写成0。方法与边界见[协议](../../../docs/evidence-support-protocol.md)。

独立源任务和生成器依赖仍有限制，复算一致只证明该程序与固定输入的一致性。原始逐例记录和可公开输入的发布、M2和M8验收仍未完成。
