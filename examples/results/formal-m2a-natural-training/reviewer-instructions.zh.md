# 本批次独立标注操作说明

本包只有公开证据和空白模板，没有标准答案。请只依据任务要求、原始输入、当前文件及本视图可见事件判断。不要检索原始实验目录、参考答案、自动评分或其他审核者的结果。

本批次共 24 个视图，每个视图 4 项要求，每位审核者应完成 24 条记录、96 项判断。视图可能来自同一任务的不同证据条件，但每个 case_id 均需单独审核，不从另一个视图补充本视图不可见的历史。

1. 保留一份收到的原始包，另存自己的 review-template.jsonl 副本。使用协调人登记的稳定审核者 ID，不与另一位审核者共用文件。
2. 对照 cases.jsonl，逐项阅读 request 中的原文要求与 hard 属性，检查 inputs、observation.files 和 observation.events。
3. status 只能填写 satisfied、violated 或 unknown。证据不足时使用 unknown，不根据常识猜测未显示的操作。当前快照改变可证明输入被改；当前快照恢复不能证明历史从未改写。
4. evidence 使用 request、input:<路径>、file:<路径> 或 event:<索引>。events 为 null 时不能引用事件。已知判断必须给出确实支持判断的可见证据，不能只填一个无关但存在的索引。
5. 完成全部要求后填写本人 reviewer，并只在实际人工审核后填写 human_verified=true。不要用模型批量填表后直接声明完成独立人工审核。
6. 分别交回 reviews-A.jsonl 或 reviews-B.jsonl。独立提交锁定前不看对方答案；发现题意或证据问题，另行记录给协调人，不私自改题。

协调人先做格式检查，再比较两份独立提交；存在状态或证据分歧时，交给与两位初审人均不同的第三人仲裁。初审与仲裁都保留原始版本，不覆盖历史记录。

当前模板 reviewer 与 status 均为空，human_verified=false。这是待审核材料，不能作为已核验监督数据。
