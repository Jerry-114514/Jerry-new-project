# 开发代理与正式主检验的功效敏感性

2026-10-23。已完成全部开发A/B3评分后，读取150个开发源、原600个注入视图的配对错误率差，A−B3均值0.08833、样本标准差0.10548。该批尚不包含后来新增的32个自然和32个长历史验证视图。B3是在同一开发集选出的，因此该效应和波动可能乐观；它们不能冒充尚未训练的D/B分布或最终664视图的波动。未读取测试模型结果，未新增模型调用或调整测试源数。

规划保留原定200个测试源、每个已见操作族25个，另100个OOD源。5个百分点改善作为敏感性目标，不承诺当前预算可对它达到80%功效；更小效应或高波动下的负结果应主要依据效应及区间解释，不能说方法等效。样本量保持原方案的任务规模，不能为了获得显著性在测试揭晓后追加题目或修改分母。

模拟直接采用主检验的双侧源任务符号翻转、10000次随机赋号、conservative plus-one p值、alpha=0.05。先用相同Python随机符号序列核对向量化实现与生产sign_flip_test，p值精确一致。每场景/效应400次重复；下面区间只度量模拟误差，不包含真实功效未知带来的不确定性。

| 假设场景 | 2.5个百分点改善检出率 | 5个百分点 | 7.5个百分点 |
| --- | ---: | ---: | ---: |
| 开发A/B3族内居中残差取绝对值后随机赋号 | 96.5% | 100% | 100% |
| 同一残差幅度加倍 | 43.0% | 94.5% | 100% |
| 对称有界双点差值，SD=0.3 | 22.25% | 59.75% | 93.0% |
| 对称有界双点差值，SD=0.5 | 11.0% | 25.75% | 58.25% |

四种场景的零效应拒绝率分别4.25%、4.75%、3.25%、4.25%。这是构造了符号可交换性的假设模拟，不能用其接近5%证明实际任务满足该前提。各任务差值均在[-1,1]内，无剪裁；每族独立抽25个源。5个百分点的SD=0.3/0.5场景模拟Wilson区间分别[54.87%,64.44%]、[21.71%,30.25%]（精确值以JSON为准）。

该模拟条件于固定训练模型，不估计训练种子总体不确定性；没有模拟blocked/fault配额或近邻相关，不能证明源独立性、bootstrap区间覆盖率或Holm次要检验功效。族内居中与随机赋号会改变经验误差分布；两种代理场景尤其不能当作实验成功概率。允许最后结果不显著，不能将代理场景100%写成实验成功率100%。

此证据补足先前仅正态假设网格的缺口，为最终协议提供可复算的主检验敏感性及固定样本量理由；不是协议已冻结或所有科学门槛通过。冻结仍须绑定最终候选、控制器完整结果、成本及测试封存，并保留以上局限。公开[全部16场景、输入校验与实际运行驱动](../examples/results/formal-m3t-development-power/README.md)。
