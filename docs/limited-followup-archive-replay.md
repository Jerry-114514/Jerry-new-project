先取得已实际异机校验的私有`final-data.tar.gz`和原回执中的SHA256。需要当前仓库的Git历史能读取协议指定的科学源码commit及分析源码commit；工具从Git对象复制公共源码到新工作区，并逐个核对冻结分析工具哈希。必须用新的Python进程运行，防止已导入的其他版本`intentlab`混入。

```sh
python scripts/replay_limited_followup_archive.py --archive /private/final-data.tar.gz --expected-sha256 SHA256_FROM_PRIVATE_RECEIPT --out /private/new-replay-workspace
```

前置检查包括：整个归档及全部成员字节、原协议锁、完整运行状态、预测封存清单及其全部文件、模型绑定、完整损失阶段、分析完成状态、输入哈希、300个不同声明源ID及200/100划分、九条件各300份预测、程序gold和场景配额。预测未封存或运行仅部分完成时，不解码gold或签发完成凭据。
