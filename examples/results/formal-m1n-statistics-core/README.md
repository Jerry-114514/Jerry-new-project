## 文件与复核

- `matrix/research-statistics.json`：实际流水线后的统计算术报告，明确 `m8_complete=false` 及剩余工作。
- `matrix/` 其余目录：完整开发选择、训练、M5/M6/M7 原始证据，全部失败保留。
- `tests-autodl.log`、`tests-local.log`：完整测试及明确跳过项。
- `runtime-identity.json`、`source-comparison.json`：远程实际环境和归档时源码/配置一致性，不是逐行覆盖率证明。
- `statistics-verification.json`：离线重算 18 个比较及注册家族；源任务不足时保留 null。
- `audit-tamper-checks.json`：更改家族大小、六模型目标 token 人口或原始任务错误率均被拒绝。

复核不需 ML 依赖：

```bash
python scripts/audit_research_statistics_evidence.py
```

该命令先重算 M5/M6/M7，再重算任务、种子、损失和次要家族。临时模型二进制未归档，不重跑模型前向，不等于持久备份。公开 gold 均为工程合成资产，正式封存数据禁止通过此路径提前发布。
