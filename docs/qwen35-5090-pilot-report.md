# Qwen3.5-9B：RTX 5090 微调、误差与资源实测报告

日期：2026-10-22。模型从[官方 Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B)原始权重初始化，revision 为 `c202236235762e1c871ad0ccb60c8ee5ba337b9a`，未加载旧项目适配器。四个基础权重分片均通过固定 SHA256 核验。旧仓库 Jerry-vibe-coding 仅作为模型身份、环境和恢复资料的参考。

**本轮确认：5090 能运行当前 QLoRA 配置；小规模合成数据上的损失、输出接口合规率和状态判断均有改善。不过，低损失没有自动保证修复安全，必须另设确定性的硬约束检查。**

## 1. 实验范围

- 4bit NF4 QLoRA，BF16 计算，LoRA rank 16、alpha 32，可训练参数 43,278,336。
- 每组 24 次优化器更新，微批次 1、梯度累积 2、seed 0、学习率上限 `5e-5`。比较余弦与 Plateau 两种成熟调度。
- 训练文件含 216 条视图、27 个任务；验证含 56 条视图、7 个任务；测试含 48 条视图、6 个任务。按操作族隔离，同一任务的变异不跨集合。
- 每组实际使用 48 个微样本，尚未覆盖一个完整训练 epoch。全部样本为代码生成的开发数据，不是人工核验的真实任务基准。
- 模型选择使用验证损失；基础模型和两个导出适配器使用相同 BF16 基础权重加载方式进行最终评测。
- 余弦组在第 12 步停止，恢复优化器、调度器及随机状态后完成第 24 步。该检查证明恢复能够完成，不宣称跨 CUDA 运行逐位一致。

原始指标见[主汇总](../examples/results/qwen35-5090-pilot-v2/summary.json)，数据、源码及适配器核验见[验证记录](../examples/results/qwen35-5090-pilot-v2/verification.json)。

## 2. 损失确实下降

以下均为相同推理精度下、按监督目标 token 加权的交叉熵。不能把训练中的 4bit 验证损失与这里的 BF16 基线直接混比。

| 模型 | 验证损失 | 测试损失 | 严格接口合规输出 |
|---|---:|---:|---:|
| 官方基础模型 | 0.209431 | 0.205846 | 5/48 |
| 余弦微调 | 0.014790 | 0.012085 | 48/48 |
| Plateau 微调 | 0.008693 | 0.007451 | 48/48 |

Plateau 组的三个训练验证点为 0.027632、0.014910、0.007203。**本轮没有触发实际的 Plateau 降学习率事件**，因此不能将改善归因于动态反馈降学习率，更不能据此宣称新的调度算法。

## 3. 把接口格式和判断错误分开

基础模型的 43 条接口错误均为缺少顶层 `findings` 字段。它们是合法 JSON，通常使用按要求 ID 分组的对象；不能将其描述成 43 条语义判断全部错误。

为观察判断本身，另进行了一项**事后、描述性分析**：用同一程序读取 `findings` 数组或按四个 ID 分组的对象，不改变任何状态值，再与标签比较。三个模型的 48 条输出均可按该规则读取。该分析不替代严格接口门禁，也不核验引用证据的语义支持。

| 模型 | 状态判断错误 / 192 项 | 错误率 | 未知状态识别 | 违规状态识别 | 不安全硬要求“已满足”判断 / 54 次机会 |
|---|---:|---:|---:|---:|---:|
| 官方基础模型 | 51 | 26.56% | 5/42 | 10/24 | 43 |
| 余弦微调 | 23 | 11.98% | 25/42 | 18/24 | 18 |
| Plateau 微调 | 7 | 3.65% | 42/42 | 17/24 | 1 |

“不安全”指硬要求标签为 unknown 或 violated，但模型判断 satisfied。它是诊断指标，不等于实际工具动作已经被提交。

结果支持本数据上的改善，但各类误差没有同步减少：Plateau 组对未知证据处理更好，违规识别数量却略低于余弦组。不能只看总准确率。

Plateau 剩余 7 项错误均涉及输入保护：6 项在历史隐藏时把文件快照已经证明的违规判为 unknown，另 1 项在历史可见时误判 satisfied。后续需要区分“缺少历史证据”与“当前快照已经证实违规”，而不是一概弃权。

完整逐项结果和归一化规则见[错误分解](../examples/results/qwen35-5090-pilot-v2/error-decomposition.json)与[分析程序](../scripts/analyze_gpu_diagnostics.py)。本轮还缺少完整 JSON Schema 提示、少样本提示或约束解码等强基线，不能把全部收益解释为推理能力提升。

## 4. 低损失仍会放行修复回归

原始闭环只依靠模型判断保护要求。在两个测试任务上，两种微调模型均接受过包含输入覆盖的修复：任务完成率为 100%，合规成功率只有 50%，硬违规比例为 50%。这次违规是**修复新引入的**，不是已经存在而无法撤销的初始错误。

该结果已原样保留，见各模型的 `closed-loop/runs.jsonl`。执行端是刻意含错误的 ScriptedActor，模型只担任分析器；这不是自主语言模型执行任务的完整基准。

据此补充[独立修复硬约束检查](../intentlab/hard_guard.py)：

1. 拒绝修复候选中对受保护输入的写入或删除，包括先写后恢复。
2. 处理写入必须遵循真实工具验证结果；验证失败后只允许写失败报告。
3. 拒绝历史记录改写以及未被事件记录的输入快照变化。

检查只读取公开输入路径、规范和工具事件，不调用最终 oracle，不读取隐藏参考答案。候选在克隆状态中检查，通过后才提交。它只保障已经编码的修复约束；不覆盖故意保留的初始错误轨迹，也不证明任意自然语言目标正确。

补充复测结果见[硬约束验证汇总](../examples/results/qwen35-hard-guard/summary.json)。它是发现失败后的工程补充，使用同两个任务，不作为预先登记的统计实验。

两个任务分别运行两种策略，每个模型共 4 次运行，但仍只有两个独立任务。

| 模型 | 无独立检查的合规成功 | 加独立检查的合规成功 | 加检查后的硬违规 | 拦截的候选数 |
|---|---:|---:|---:|---:|
| 官方基础模型 | 0/4 | 0/4 | 0/4 | 0 |
| 余弦微调 | 2/4 | 4/4 | 0/4 | 2 |
| Plateau 微调 | 2/4 | 4/4 | 0/4 | 2 |

当前 46 项测试通过，新增测试包括模型错误宣称输入安全时仍拒绝回归、写后恢复、验证失败后的报告例外及无验证的数据写入。动态策略与 fixed-full 在本轮表现一致，没有证据说明动态策略优于该强对照。

## 5. 5090 的显存与主机内存是否足够

**当前配置足够，但本轮没有进行 4096 tokens 满长度压力测试。**

| 指标 | 实测值 |
|---|---:|
| 5090 可用显存总量 | 32607 MiB，约 31.84 GiB |
| 余弦组训练/验证阶段峰值 allocated | 17.37 GiB |
| 余弦组训练/验证阶段峰值 reserved | 26.57 GiB |
| Plateau 组峰值 allocated / reserved | 17.49 / 24.09 GiB |
| 按最大 reserved 计算的余量 | 约 5.27 GiB，尚需容纳 CUDA 等额外开销 |
| 已观测训练进程主机内存高水位 | 约 17.77 GiB |
| 实例容器主机内存限额 | 90 GiB |

allocated 是活跃张量占用，reserved 包含缓存池，二者不能相加。`free` 显示的约 754 GiB 是宿主机总内存，不能当作本实例的资源配额；容器限额来自 `/sys/fs/cgroup/memory.max`。

样本长度上限实际为训练 1245、验证 1176、测试 1392 tokens，均包含目标文本。微批次为 1。更长上下文、更大微批次和全参数微调需另测，不能套用当前峰值。主机内存观测来自一次进程高水位读取，不是所有进程的完整峰值记录。

余弦组训练循环合计约 62.48 秒，Plateau 组约 61.02 秒，包含训练内验证和检查点保存。含加载的训练调用墙钟分别约 129.44 秒、98.38 秒；余弦多一次恢复加载。下载、首次内核编译、生成评测等另计，不能把这些数值当作公平的调度器速度比较。

资源记录见[观测文件](../examples/results/qwen35-5090-pilot-v2/resource-observations.json)。量化日志中的 `parameters` 是存储张量元素数，不能当作原始模型参数规模；模型身份由官方版本和权重 SHA 确定。

## 6. 可复现资料与后续工作

- 原始训练和主评测源码对应 GitHub commit `c4d1b5997a9b39ec501b3515602b1635ca60ef17`，源码及数据指纹记录在运行清单中。当前版本另含独立硬约束补丁；重现未加补丁的闭环应使用原提交。
- 更早的开发运行因提示未公开要求 ID 而停止评测，保存在 `development-v1`，不用于效果结论。修订版对基础模型和微调模型公开相同要求定义，不给出状态标签。
- 两个适配器各约 173 MB，及其恢复检查点保存在 AutoDL 数据盘。路径、SHA256、张量数量和有限值检查见[模型资产索引](../examples/results/qwen35-5090-pilot-v2/model-artifacts.json)。GitHub 保存代码、SFT 数据、原始生成、指标和索引，不包含这两个大权重文件。
- 首先补充完整输出 Schema 的强提示基线，以及快照证明违规、长历史、多次修复等训练反例。新反例不能直接复用这 6 个测试任务；确认性结论需要新的隔离测试集、人工核验轨迹和至少三个训练种子。
- 已有确定性工程成果是可复现训练、恢复、可追溯错误分解和独立修复约束。学习率创新、真实任务泛化、评分校准和动态策略优势仍未得到本轮证明。
