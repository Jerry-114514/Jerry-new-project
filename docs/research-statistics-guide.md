# M8 统计核心：单位、配对与检验范围

这是统计计算核心及冻结规则，不是 M8 完成声明。统计阶段凭据、候选误拦截与共同可行性分析已补充工程实现，见[入口说明](candidate-statistics-guide.md)。正式数据/实验、科学前提审核、持久模型备份及最终报告仍待完成。工程验证只用明确合成的算术夹具和真实微型模型记录。

## 冻结前明确的方法

正式协议的 `statistics.analysis_plan` 必须完整匹配已实现的方案；空缺或临时改变方法会被准备检查拒绝。工程旧协议允许显式标识的默认计划推断，不能当成正式预注册。方法与注册范围在真实正式测试尚未揭晓前补齐，理由是原协议缺少种子汇总、检验和完整校正范围；没有根据正式结果挑方法。

这套方案依赖实际独立的源任务和成对效应在零假设下的可交换性/符号对称性。代码只能核对 ID 与原始记录，不能证明抽样独立或检验前提。其 sign-flip p 值不是在任意分布下检验“均值相等”的保证；正式科学审核须确认前提或在测试前修订方案。NLP 检验选择与数据依赖问题参考 [Dror 等的检验指南](https://aclanthology.org/P18-1128/)，本项目的源任务聚合是实现中的显式设计。

## 统计单位和种子

先在每个 `source_task_id` 内对视图/执行变体取平均，再对源任务等权。所有策略按相同源任务保持配对，test 与 OOD 分开，不合并来扩大显著性。

RQ1 为完整 Schema 加人工审核少样本的 B 对余弦 D。三个 D 种子各保留结果；先求同一任务上的三个配对效应均值，再按任务求总体差异。原始 B 在种子向量中重复只是对齐，不能算作三次独立训练。报告各种子效应及其样本标准差；bootstrap 始终把三个固定种子一起随任务移动，不重抽训练种子。

区间只描述这些已训练模型条件下的任务抽样差异，不是训练种子总体的置信区间。三个种子的样本标准差也不是总体置信区间。若需要训练过程总体推断，须另行设计并在测试前登记，不能把三个种子乘以任务数作为独立样本量。

## 各问题的固定差异

所有差异采用右减左，方向同时写入输出：

| 比较 | 左侧 | 右侧 | 有利方向 |
| --- | --- | --- | --- |
| RQ1 | B 状态错误率 | D 三种子平均状态错误率 | 负 |
| RQ2 | P1 修复新增硬违规指示 | P3 同指标 | 负 |
| RQ3 | P3 合规成功 | P4 合规成功 | 正 |
| RQ4 | D 目标 token 加权损失 | E 目标 token 加权损失 | 负 |
| M7 固定控制 | 每个已登记 fixed-k | dynamic-k 合规成功 | 正 |
| M7 权重控制 | dynamic-k | 对应移除权重条件的合规成功 | 正只表示右侧较高 |

RQ2/RQ3 的当前主要计算保留全部任务及失败。初始不可逆违规、修复机会和错误数另列；共同可行子集和候选误拦截尚待补齐，不把个别条件可行分母的差异当作配对效果。没有任何修复机会时，零新增违规不能说明检查器有效或保证安全。

RQ4 先按任务保存各模型的 loss_sum 和 target_tokens，再计算 `总 loss_sum / 总 target_tokens`。每次 bootstrap 重抽整个任务的全部损失和分母，重新求比值；不能平均每条样本交叉熵，也不能给长短目标相同 token 权重。六组必须使用完全相同的案例、目标数量和种子配对。

## 重采样和 p 值

任务聚类 bootstrap 使用冻结的重复数和种子。每次按原任务数有放回抽取源任务，保留任务内所有变体、条件和固定种子的配对关系。95% 区间取排序后第 `floor(.025*(B-1))` 与 `floor(.975*(B-1))` 个值，属于边际百分位区间。

成对符号翻转以任务为单位，同时翻转该任务的固定种子平均效应；加权损失翻转任务损失差的分子，分母不变。非零任务贡献不超过 16 个时枚举全部符号；更多时使用冻结的 10,000 次独立随机翻转，按包含相同或更极端统计量的次数计算保守 `(b+1)/(B+1)` p 值，避免随机抽样给出零。该保守处理及限制参考 [Phipson 与 Smyth 的原论文](https://gksmyth.github.io/pubs/permp.pdf)。比较统计量时使用固定 `1e-12` 相对/绝对数值容差。保留输入、算法及种子以便重算，不逐次归档所有符号排列。

test 或 OOD 少于两个源任务时，区间和 p 值均为 null，保留点估计与实际分母。两个任务仅是实现的最低门槛，不代表功效足够。常数样本可能产生退化 bootstrap 区间；尤其零次违规不能外推为总体风险为零。

## 预先固定的多重比较族

唯一主比较是 RQ1/test。次要族统一包含：RQ2/RQ3/RQ4 的 test 与 OOD、RQ1/OOD，以及两个 split 上的全部 M7 固定 k 和两种权重控制。默认 max_k=3 时共 17 个次要检验，不因某组失败、不利或无法计算而删减。

次要 p 值采用 Holm 单调逐步校正；无法计算的比较仍占家族大小，原始/校正 p 值都保留 null，不伪装成已计算的 1。实现与保留未观测比较数量的原则参考 [R 官方 p.adjust 文档](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html)，原方法为 [Holm (1979)](https://www.jstor.org/stable/4615733)。Holm 不能补救无效的原始 p 值或不成立的抽样假设。

每种子的结果属于描述性分解，不另立三次主检验。A/C/E 的诊断指标、成本和其他辅助结果继续保留，不根据它们的成绩改主次关系。当前 95% bootstrap 区间是边际区间，Holm 只调整所登记的 p 值，不将这些区间变成同时覆盖区间。

## 实现、证据与未完成项

`intentlab.research_statistics.analyze_records` 是纯离线算术接口，不读取模型、gold 或训练状态。新增 `intentlab.frozen_statistics` 在计算前后递归验证冻结协议、模型、M5/M6/M7 完成凭据和原始记录，并在验证时重算报告；这是统计阶段凭据，不是正式 M8 完成凭据，不可绕过前置验证直接发布正式结论。

[M1n 工程证据](../examples/results/formal-m1n-statistics-core/README.md)包含解析可手算的单元检验及完整微型模型流水线。每个 split 只有一个源任务，因此 18 个比较的区间/p 值均为 null；保留完整 17 项校正家族，不把三种子或重复运行虚报成足够样本。

候选机会和共同可行交集是描述性辅助分析，不改变主次检验族。正式实验和科学前提审核、长期权重备份及最终报告仍未完成，原 M1–M8 目标不变。
