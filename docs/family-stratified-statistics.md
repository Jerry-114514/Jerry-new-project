# 固定操作族配额下的任务簇重采样草案

2026-10-23。在任何测试模型评估前，补充analysis_plan v2。当前程序候选对已见八族设固定任务配额，OOD也固定族配额；原v1在全体source_task_id中抽样，会同时改变族组成。新选项先按操作族分组，在每族内有放回抽取相同数量的源任务，保留三种子向量、所有派生视图及损失分子/目标token分母。实现遵循已有的[族内分层重采样做法（R boot官方文档）](https://stat.ethz.ch/R-manual/R-devel/library/boot/html/boot.html)，不引入新的模型或学习算法。

该设计估计条件于固定操作族配额的任务间波动。点效应、三种子配对汇总、目标token加权loss、一个主要比较、17个次要比较的Holm族均不改变。源任务是抽样单位，证据视图和训练种子不增加独立n。原v1仍可显式使用，旧工程结果不重写；同一旧算术夹具已用变更前源代码和当前v1入口重算，完整报告逐字段一致。

v2使用冻结执行记录中已经绑定的family元数据，要求同一源任务在条件及变体间保持同一操作族。混合族来源需先明确设计，不能静默取第一条。每族少于两个源时保留描述性效应，但本版本保守地不输出CI/p值；未定义次要检验仍留在Holm族大小中。所有配对seed随源任务一起重采样，不从三个种子构造训练随机性总体CI。

## 假设和未解决事项

分层只固定操作族配额，**不固定缺字段cadence、单故障轮换或其他生成器配额**；并非对整个数据生成设计做精确抽样推断。仍需族内来源抽样假设；来源/模板近重复的语义限制也仍在。符号翻转检验保持原定义，仍要求独立簇及配对效应在符号反转下的可交换性，不自动成为任意“均值相等”的检验。分层不能消除这些假设。

百分位区间仍是近似方法，不能用该改动承诺覆盖率、显著性或更窄区间。M3i假设功效网格也不能直接当作v2实际功效；应在开发数据、最终样本设计和最终算法下另做校准。此处未读取私有测试标签、模型测试成绩或未完成基线的诊断成绩。

## 工程证据与协议状态

新增五项测试覆盖族配额、加权loss分母、固定seed向量、单例族拒绝推断、完整比较族及族身份冲突。算术示例中两个族的差值人为固定为+1和−1，点效应均为0；普通任务重采样区间为[-1,1]，固定族配额区间为[0,0]。这是重采样设计的演示，不是模型效果、真实方差或覆盖率验证；退化区间不证明不存在罕见失败。

另已验证v2封存统计入口在删除gold/参考后完成计算及收据复核，仍为合成夹具。本地256项测试含14项ML跳过，其余通过。证据在[M3m](../examples/results/formal-m3m-family-strata/README.md)。程序标签正式草案已选择v2，仍未冻结；旧人工协议草案和v1历史保留。AutoDL运行中的基线、采集及压力测量继续使用固定b4a757a源码，不部署本变更。正式数据、预算、控制器、封存及最终科学假设审查仍待完成，M8未完成。
